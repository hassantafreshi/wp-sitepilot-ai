# راهنمای کاربر AI Site Assistant AutoPilot

این پوشه مقاله‌های راهنمای مدیران سایت را نگه می‌دارد: کارمحور، فارسی و با تصویرهایی که مستقیم از خود افزونه گرفته شده‌اند. مستندات توسعه‌دهنده در [`docs/technical/`](../technical/README_FA.md) است.

## ساختار

| مسیر | محتوا |
|---|---|
| [GUIDE_PLAN_FA.md](GUIDE_PLAN_FA.md) | فهرست کامل ویژگی‌ها، صف ۳۶ مقاله، کمبودهای ابزار، یافته‌ها و journal |
| [WRITING_GUIDE_FA.md](WRITING_GUIDE_FA.md) | قواعد صداقت، نگارش فارسی، واژه‌نامهٔ رابط، تصویر و چک‌لیست انتشار |
| [ARTICLE_TEMPLATE_FA.md](ARTICLE_TEMPLATE_FA.md) | قالب هر مقاله |
| `fa/` | مقاله‌های فارسی |
| `en/` | مقاله‌های انگلیسی، فقط با درخواست مالک |
| `screenshots/` | plan تصویر هر مقاله برای `scripts/agent/docs-screenshot.cjs` |
| `images/<slug>/<locale>/` | تصویرهای ساخته‌شده با ابزار |

این پوشه در ZIP انتشار افزونه قرار نمی‌گیرد.

## اجرا

نویسندهٔ این راهنما agent `aisa-docs-writer` است (`.claude/agents/aisa-docs-writer.md`):

| فرمان | کار |
|---|---|
| `/aisa-docs` | مقالهٔ بعدی صف |
| `/aisa-docs G18` | نوشتن یا بازنویسی یک مقالهٔ مشخص |
| `/aisa-docs ادامه` | نوشتن پشت سر هم تا رسیدن به مانع |
| `/aisa-docs status` | گزارش فقط‌خواندنی صف |
| `/aisa-docs audit` | بازبینی مقاله‌های نوشته‌شده با کد، ترجمه و رابط فعلی |

agent هر مرحله را روی سایت محلی بازتولید و برچسب‌ها را با ترجمهٔ فارسی تطبیق می‌دهد. تصویرها را با کاربر موقت، fixture بازگردان و پاسخ‌های ساختگی REST می‌گیرد، تا هیچ درخواستی به سرویس هوش مصنوعی، ایمیل، پیامک یا Telegram نرسد. وضعیت «تأییدشده» را فقط مالک پس از خواندن مقاله ثبت می‌کند.
