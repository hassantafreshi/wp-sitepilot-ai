# برنامهٔ راهنمای کاربر: فهرست ویژگی‌ها و صف مقاله‌ها

این سند صف کار agent `aisa-docs-writer` است و مالک پیشرفت راهنمای کاربر را از روی آن دنبال می‌کند. قواعد نگارش و تصویر در [WRITING_GUIDE_FA.md](WRITING_GUIDE_FA.md) و قالب مقاله در [ARTICLE_TEMPLATE_FA.md](ARTICLE_TEMPLATE_FA.md) است. فرمان اجرا `/aisa-docs` است (بخش «اجرا» در [README_FA.md](README_FA.md)).

نسخهٔ مبنا: افزونهٔ 1.0.4 روی سایت محلی `http://127.0.0.1/wp`.

## وضعیت‌ها

| وضعیت | معنا | تعیین‌کننده |
|---|---|---|
| منتظر | هنوز شروع نشده | agent |
| در حال نوشتن | research، تصویر یا متن در جریان است | agent |
| نوشته‌شده | همهٔ مراحل بازتولید، تصویرها بازبینی و چک‌لیست راهنمای نگارش کامل شده است | agent |
| تأییدشده | مالک مقاله را خوانده و پذیرفته | فقط مالک |
| نیاز به به‌روزرسانی | audit نشان داده متن، برچسب یا تصویر با نسخهٔ فعلی نمی‌خواند | agent |
| مسدود | کار بدون تصمیم یا ابزار ممکن نیست. علت در یادداشت ثبت می‌شود. | agent |

## قرارداد فایل‌ها

| فایل | مسیر |
|---|---|
| مقالهٔ فارسی | `docs/user-guide/fa/<slug>.md` |
| مقالهٔ انگلیسی (فقط با درخواست مالک) | `docs/user-guide/en/<slug>.md` |
| plan تصویر | `docs/user-guide/screenshots/<slug>.json` |
| تصویر (ساختهٔ ابزار) | `docs/user-guide/images/<slug>/<locale>/<shot>.png` |

پوشهٔ `docs/` در ZIP انتشار افزونه قرار نمی‌گیرد.
